# DundeeMapper
Mobile App Project for CS32005

This mobile app is for the City of Dundee, Scotland. It'll be able to display where you are and places of interest within the city.

Most of the documentation can be located within the Documentation folder, any flowcharts or wireframes missing, send me an email.

Code for DundeeMapper (MainActivity Loop) is located in /src/app/src/main/"java/com/example/dundeemapper"

Main branch is stable and will run with *hopefully* little to no issues.
Experimental branch is unstable, features are half complete or buggy/

Software used:
Android Studio
